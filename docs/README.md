- **Contributor:** architecture → development → relevant implementation guide.

## Documentation conventions

Unsuffixed Markdown guides are English; `.es.md` guides are Spanish. Each page links to its equivalent and this index. The interface itself is currently English.

Installation instructions describe supported configuration paths. Validation reports describe specific past executions and do not guarantee every Flash module, event or public deployment. Keep both editions synchronized when behavior changes.

Dependency license notices retain their original legal text.
